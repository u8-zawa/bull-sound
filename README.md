# BULL SOUND

カメラでダーツボードを映し、ブルへの命中を画像差分で判定して効果音を鳴らすWebアプリです。
3投1ラウンドで ONE BULL / LOW TON / HAT TRICK の演出を表示します。

**公開URL:** https://u8-zawa.github.io/bull-sound/

## 使い方

1. スマホ（またはPCのWebカメラ）を三脚などで固定し、的が映るようにする
2. 公開URLを Safari / Chrome で開き、「① カメラ起動」を押してカメラを許可する
3. 赤い円をタップしてブルの中心に合わせ、「ブルの円の大きさ」で径を調整する
   - カメラを斜めに置いている場合は「斜め補正：縦横比 / 傾き」で円を楕円にし、映像上のブルの形に合わせる（100%・0°で真円）
4. 「② 判定開始」を押し、背景の記録が終わったら3投を投げる
5. 3投後は数字（0〜3）でブル本数を確定すると、演出のあと次のラウンドへ進む

設定は「↺ 設定を初期値に戻す」でまとめて初期値に戻せます（選んだ音声ファイルは残ります）。

### 操作

| 操作 | スマホ | PCキーボード |
| --- | --- | --- |
| 3投の結果を確定 | 「0〜3」ボタン | `0` `1` `2` `3` |
| アウター / インナー / MISS を追加 | 「＋ OUTER」「＋ INNER」「＋ MISS」 | `B` / `I` / `M` |
| 直近ブルの内外を切替 | 「↔ 直近の内外切替」 | `T` |
| 3投終了・次のラウンドへ | 「🏁 3投終了」 | `Enter` |
| 直前の記録を取り消す | 「↶ 戻す」 | `Backspace` |
| 全画面表示の切り替え | 「⛶ 全画面表示」※ | `F` |

※ PCやAndroidのブラウザで使えます（iPhoneのSafariは非対応のためボタンは表示されません）。PCではブラウザのタブやアドレスバーが消え、演出が画面全体に広がります。

## 演出

BULL / INNER BULL / ONE BULL / LOW TON / HAT TRICK は、画面いっぱいの演出（フラッシュ・放射光・紙吹雪・花火・画面の揺れ）で表示します。結果が良いほど派手になります。
離れた場所のモニターでも気づけるようにするためのもので、設定の「画面いっぱいのド派手演出」をオフにすると、カメラ映像内の小さな表示に戻ります。

- 画面の光がカメラに映り込んで誤判定しないよう、演出中とその後0.5秒は判定を止め、終わったら背景を撮り直します
- フラッシュは1秒に3回未満に抑えています。OSの「視差効果を減らす」が有効なときは、文字の表示だけになります

## 効果音

標準はブラウザ内で合成する効果音です（インパクト / アーケード / ベル）。
設定の「📁 OUTER 音を選ぶ」「📁 INNER 音を選ぶ」から、手元の音声ファイル（1MB以下）を使うこともできます。
INNERを選ばない場合はOUTERの音を使います。選んだファイルはその端末のブラウザ内にだけ保存され、「解除」で消せます。
このリポジトリに音声ファイルは含まれていません。使う音声の権利はご自身で確認してください。

## プライバシー

- カメラ映像は端末のブラウザ内だけで処理し、外部へ送信・保存しません
- 端末に保存するのは円の位置やサイズなどの設定と、選んだ音声ファイルだけです（`localStorage`）
- 外部から読み込むのは Google Fonts のみです

## 構成

`index.html` 1ファイルだけの静的サイトです。サーバーやDBは使っていません。
スマホでは1列、画面幅960px以上（PC・タブレット横向き）ではカメラ映像を横長にした2列レイアウトで表示します。
カメラの利用には HTTPS が必要なため、GitHub Pages（HTTPS）で配信しています。
